# Encrypted-Cloud-Storage-with-Access-Control
This is a project that offers a safe means of storing and exchanging files in the  cloud by employing robust cryptographic techniques.

Files are encrypted prior to exiting the user's computer, kept securely on the cloud server, and only accessible to permitted users. 

It employs AES encryption for securing contents of files and RSA encryption for securing secret AES keys when being shared. The owner of a file has controls over who may open it or download it, and permission or permission withdrawal may be used to control such access. 

This system has a higher level of security in comparison to standard storage platforms and demonstrates how cryptography and controls for access may work together for practical uses in protecting sensitive data.
